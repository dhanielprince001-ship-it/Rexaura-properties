# Rexaura Properties

Luxury real estate website built with React and Vite. No accounts or database: visitors browse listings and contact the team.

## Run
```
npm install
npm run dev
```
Build for hosting with `npm run build` (output folder: `dist`).

## Pages
- Home, Listings (`#/listings`), Property Detail (`#/property/1`) and a Contact section.
- Contact and tour-request forms open the visitor's email app addressed to rexgroups.uk@gmail.com. Call and WhatsApp use 08033564331.

## Editing
- All listings live in `src/data.js`.
- Replace the `listing-*.jpg` and `detail-*.jpg` photos in `public/images` with your own.
